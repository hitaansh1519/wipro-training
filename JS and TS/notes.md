what is Software Testing?

Software testing is the process of verifying and validating that a  software application works as expected, meets requirements, and does not produce incorrect results.

why is testing necessary?



Verification + Validation -

Verification -> Did we build the
software correctly?

Validation -> Did we build the
correct software?

Software testing prevents all
these risks.

Bug - Any deviation between expected behavior and actual behavior.

Manual testing - testing without using any automation tools.

Manual Testing is time consuming.

In order to speed up the testing we use Automation Testing.

Automation can't replace Manual Testing.




I dont need Nodejs if I want to run JS right inside the browser.

Why? All the browsers have JS engine inbuilt.

But if I want to execute JS outside the browser for example VSCode, then I need Nodejs.

Open command prompt and type: node -v

npm - Node package manager

The purpose of Node.js is to run JavaScript outside the browser.

The purpose of NPM is to install any third-party library. Example - Playwright

You don't install NPM separately. NPM comes automatically along with Node.js installation.

The simplest way of opening a folder in VS Code is just drag and drop the folder.

VS Code provides its own integrated terminal so that I don't have to go outside VS Code if I
want to run anything via command prompt.

Now, there are three ways of opening the terminal in VS Code.
1. Terminal -> New Terminal
2. Opening terminal from the bottom panel.
3. Press the keys Control and backtick(")

Optionally, you can press Ctrl+J on a Windows machine.

Turn on the auto save feature in VSCOde. File -> Auto Save.

In order to clear the terminal, either in the browser or in VS Code, the shortcut is Ctrl+L
keys.
